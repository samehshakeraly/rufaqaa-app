منطقة الخطر

إجراءات لا يمكن التراجع عنها بسهولة. كلّ إجراء يحتاج تأكيداً مزدوجاً + تسجيلاً في سجلّ التدقيق.

تصدير كامل لبيانات المؤسسة
ملفّ JSON + CSV يحوي كلّ بيانات الأيتام والكفلاء والمعاملات. يستغرق إنشاؤه عدّة دقائق ويُرسَل إلى بريدك.
تجميد المؤسسة مؤقّتاً
يوقف استقبال تبرّعات جديدة لكن يبقي التقارير والوسائط تعمل. مفيد أثناء عمليّات صيانة كبرى أو مراجعات قانونيّة.
نقل المؤسسة إلى مالك جديد
نقل ملكيّة المؤسسة لمدير عام آخر. يحتاج توقيعاً من ولي الأمر الحالي + مدير المنصّة + توثيقاً قانونياً.
حذف المؤسسة من رفقاء
سيُحفَظ نسخة قانونيّة للبيانات لمدّة 7 سنوات (متطلّب رقابي) ثم تُتلَف. الإجراء غير قابل للتراجع.
