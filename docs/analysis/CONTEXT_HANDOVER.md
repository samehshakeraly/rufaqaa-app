## 📋 ملخص سريع للمشروع

### الهوية
```
الاسم: رفقاء (Rufaqaa)
الدومين: rufaqaa.app
الشعار: "كافل اليتيم.. رفيق النبي ﷺ"
المصدر: حديث "أنا وكافل اليتيم في الجنة هكذا"
الطبيعة: وقف إلكتروني — أحد أوقاف سامح عبد العزيز
الرخصة: MIT (مفتوحة المصدر)
```

### الفكرة
```
منصة عالمية تربط بين:
  - الأيتام (المستفيدون)
  - أولياء أمورهم (الوصاة)
  - الجهات الشريكة المحلية (مثل الأورمان مصر)
  - جهات التسويق الخارجية (مثل النجاة الكويت)
  - المتبرعون (الكفلاء) ← الأهم!
  
بتقنية متطورة + MCP لـ Claude AI + شفافية كاملة
```

### Stack التقني
```
Backend:       Python + FastAPI
Database:      PostgreSQL 15+
Frontend:      React + TypeScript
Mobile:        React Native (4 تطبيقات)
Cache/Queue:   Redis + Celery
Search:        PostgreSQL Full-Text
Storage:       S3-compatible + CDN
Auth:          JWT + 2FA + OAuth2
MCP:           Python SDK من Anthropic
```


## 💡 قواعد التعامل في المحادثات الجديدة

### القواعد الذهبية

```
1. ✅ كل قرار يجب أن يحترم روح المشروع كوقف
2. ✅ كل تفصيل يخدم اليتيم والكافل بكرامة
3. ✅ المرجع الأول هو rufaqaa_full_analysis.md
4. ✅ لا تكرار في البيانات (قاعدة جوهرية)
5. ✅ Multi-Tenancy في كل قرار تقني
6. ✅ الأمان قبل السرعة
7. ✅ الشفافية قبل الراحة
8. ✅ احترام الخصوصية (خاصة للأطفال)
```

### الأخطاء التي يجب تجنبها

```
❌ لا تقترح حذف ميزة موجودة في الوثيقة دون نقاش
❌ لا تغيّر القرارات التقنية المعتمدة
❌ لا تتجاوز قواعد سلامة البيانات
❌ لا تقترح ميزات تخالف قيم الوقف
❌ لا تستخدم MySQL (نحن على PostgreSQL)
❌ لا تستخدم MongoDB (نحن SQL-based)
❌ لا تقترح حلول ربحية تتعارض مع طبيعة الوقف
```
